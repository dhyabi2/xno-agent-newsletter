# 2026-10-26: profullstack's x402 gateway can offer buyers a Nano (XNO) option

Window: 2026-10-25 05:20 UTC to 2026-10-26 05:20 UTC. The item below is a merged pull request on a public
repository, checked on its own page.

**x402-gateway can add an XNO offer next to its existing ones.** A merchant who sets a Nano payee and a rate now gets
an extra XNO payment option on its x402 offers. The buyer pays by publishing a Nano send block, and CoinPay checks
that block against a Nano node before the request goes through. The option is off unless the merchant configures it,
so existing offers do not change. It ships as version 0.14.0. The maintainer merged it on 2026-10-26 at 00:04 UTC
(commit `ff5e2de`).
