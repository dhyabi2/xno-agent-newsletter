# xmcp's x402 package now binds Nano payments to orders

**basementstudio/xmcp: Nano claims survive restarts, and payments bind to an order.** Pull request #772 was merged into main on 2026-11-15 at 13:57 UTC (merge commit a442edc) by the project's maintainer. It shipped the same hour in `@xmcp-dev/x402` 1.2.0 on npm. An MCP server that sells tools over x402 and takes Nano can now set `nano.claimsFile`, so a block hash it has already credited stays used after a restart. It can also set `nano.requireBinding`, so each payment has to commit to the order id of its own 402 offer, at the exact amount. Proof: https://github.com/basementstudio/xmcp/pull/772 and https://www.npmjs.com/package/@xmcp-dev/x402/v/1.2.0

```
curl -sS https://registry.npmjs.org/@xmcp-dev/x402/-/x402-1.2.0.tgz | tar xzO package/dist/types.d.ts | grep -n requireBinding
```
