# The open-402 directory now rejects mistyped Nano payout accounts

**ArcedeDev/open-402 merged a Nano account checksum check (2026-11-27 20:41 UTC, pull request #71, merged by the maintainer).** open-402 is a public directory of services that charge agents over HTTP 402. Before this change, a declared Nano payout account was checked only for its shape, so an account with one wrong character could still take a slot in the verification queue. Now the last 8 characters, a BLAKE2b checksum of the public key, must match before the account is queued, so a typo is refused at the door instead of being sent money it can never receive. The check needs no dependency beyond the language. No fix of ours is open on this repository. Proof (the merged file, at the merge commit bf28d8d): https://raw.githubusercontent.com/ArcedeDev/open-402/bf28d8ddc251d17577dfc649c0827101a0cb294b/scripts/lib/nano-address.ts (the pull request: https://github.com/ArcedeDev/open-402/pull/71)
