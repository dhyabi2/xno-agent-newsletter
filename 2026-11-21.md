# Fetch.ai's examples repository now has a seller agent paid in XNO

**fetchai/innovation-lab-examples#188 merged (2026-11-20 07:29Z).** Fetch.ai's examples repository now includes `contributors/nano-xno-payment-agent`, a uAgents seller example that takes payment in Nano (XNO). It adds a `nano_xno` payment method beside the existing `fet_direct` and `skyfire` methods, using the same Funds / RequestPayment / CommitPayment messages. The seller looks up the buyer's send block on a public Nano node and accepts it only if it is a confirmed send to the seller for the exact amount. Each block is credited once. An agent builder using that protocol can copy it and accept a fee-less payment that settles in about a second, with no account at a payment company. Merge commit 9a927ad19b0cc6493f7487e1e38cc482a004dfda on main (15 files, 3 offline test files). https://github.com/fetchai/innovation-lab-examples/pull/188

```
git clone -q --depth 1 https://github.com/fetchai/innovation-lab-examples && ls innovation-lab-examples/contributors/nano-xno-payment-agent
```

**xno-call-binding 0.2.1 is on PyPI (2026-11-20 07:59Z).** This package binds a Nano payment to the call it paid for, so a seller can tell which request a given block paid for. It uses the standard library only and needs no key. Network access is limited to the read-only node and price helpers, and it never connects at import. https://pypi.org/project/xno-call-binding/0.2.1/

```
curl -s https://pypi.org/pypi/xno-call-binding/0.2.1/json | python3 -c "import json,sys; print(json.load(sys.stdin)['info']['version'])"
```
