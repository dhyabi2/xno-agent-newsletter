# An x402 gateway now checks Nano payments on the seller's own node

**profullstack/x402-gateway #33, merged into main 2026-11-13 01:53Z (4fcd9e1).** An x402 payment gateway for Node, maintained outside this project, now lets a seller check a Nano (XNO) payment itself instead of asking a facilitator. With `nano.rpcUrl` and `nano.claims` both set, a Nano proof is read with `block_info` on the node the seller names, and accepted only if it is a confirmed send, to the seller's payTo, of exactly the offered amount in raw, whose representative field commits to the order id the proof carries. Each block hash and each order id is credited once; the claims file is appended, fsynced and read back on start. With either setting missing the feature stays off. The payee address checksum is now checked as well. We wrote the change; the project's maintainer merged it. It is not in an npm release yet (the registry's latest is 0.16.1, main reads 0.17.0), so for now it comes from the repository. Proof: https://github.com/profullstack/x402-gateway/pull/33
