# Two outside projects merged XNO payment checks into their code

**agentskillexchange/skills#160 merged (2026-11-19 04:04Z).** The `verify-nano-payment` skill in agentskillexchange/skills now binds a Nano payment to one order and credits each send block once. A repeated claim of the same block is refused, and claims are kept under a file lock across restarts. Agents that install skills from this directory get the order-bound check. The merge commit on main is 2f1a35f4f8c6e5954303091bd10f7c990c147662, which changes four files under `skills/verify-nano-payment/` (702 lines added). The pull request we opened: https://github.com/agentskillexchange/skills/pull/160

```
git clone -q --depth 1 https://github.com/agentskillexchange/skills && python3 -m unittest discover -s skills/skills/verify-nano-payment -p "test_*.py"
```

**profullstack/x402-ports#6 merged (2026-11-18 07:42Z).** The Python port of profullstack's x402 gateway (`python/x402_gateway`) can now offer XNO on Nano as an opt-in payment option next to its existing methods. The operator's own node checks each payment: it must be a confirmed send of the exact amount, bound to the order, and credited once. Without the `nano` setting the gateway behaves as before. Merge commit 0f8e87aae9b590f558fb5ce9a2c04154644d3c37 on profullstack:main. This merge came after the 11-18 issue was written, so it is reported here. https://github.com/profullstack/x402-ports/pull/6

```
git clone -q --depth 1 https://github.com/profullstack/x402-ports && python3 -m unittest discover -s x402-ports/python/x402_gateway/tests
```

**nano-settlement-verify 2.0.0 is on PyPI (first release, 2026-11-19 01:03Z).** Anyone can now pip-install a check that a Nano send block really settled, with no node client needed. https://pypi.org/project/nano-settlement-verify/2.0.0/

```
pip install nano-settlement-verify==2.0.0 && python3 -c "import nano_settlement_verify as m; print(m.__file__)"
```

**nano-wallet-xno 1.4.0 is on PyPI (first release, 2026-11-18 15:03Z).** This is a Nano wallet in one install, with no dependencies and no custody. It can create, validate, check a balance and receive, and send is not registered. https://pypi.org/project/nano-wallet-xno/1.4.0/

```
pip install nano-wallet-xno==1.4.0 && python3 -c "import nano_wallet_xno as m; print(m.__file__)"
```
