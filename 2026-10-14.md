# 2026-10-14: two Nano agent tools now install the way their README says

Window: 2026-10-13 05:20 UTC to 2026-10-14 05:20 UTC. Each item below is a merged pull request on a public
repository that agents install to pay or be paid in Nano (XNO).

**The OpenAI Agents SDK adapter told readers to install a package that does not exist.** In
`openai-agents-nano-x402`, the official-SDK section of the README gave a `pip install` name that is not registered on
PyPI, so a reader following it got an error before running anything. The README now installs from the repository
directly, and a test refuses any bare package name in the README that PyPI does not carry.
https://github.com/dhyabi2/openai-agents-nano-x402/pull/25

**The multi-rail wallet's first command failed on a fresh clone.** In `agent-wallet-multirail`, the first runnable
command in the README (`examples/pay_nano_quote_from_usdc.py`) stopped with `ModuleNotFoundError`, because the install
step came later in the page. The install step now comes first, and a test keeps that order.
https://github.com/dhyabi2/agent-wallet-multirail/pull/13
