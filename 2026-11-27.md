# An agent skill catalog now lists a skill that pays Nano 402s

**agentskillexchange/skills merged nano-fetch (2026-11-26 20:23 UTC, pull request #181).** The catalog's agents can now pick up a skill that fetches a URL and, when the server answers HTTP 402 with an x402 `nano:mainnet` exact quote, pays it once through the operator's own signer and retries with the proof. A per-call cap and a total budget are checked before anything is signed, the send is bound to that one order, and a journal refuses to pay the same order twice, also after a restart. The skill holds no key and no seed. The catalog ships from its main branch, so the merge is the release.
