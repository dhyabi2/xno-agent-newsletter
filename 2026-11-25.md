# xmcp servers can now offer Nano payments in the x402 v2 format

**@xmcp-dev/x402 1.4.0 (late item: released 2026-11-22 20:35 UTC, not in an earlier issue).** An MCP server built with xmcp can now answer an unpaid Nano tool call with an x402 version 2 offer, by setting `nano.x402Version` to 2 for that network. The default stays version 1, so existing servers and clients see no change. This came from basementstudio/xmcp#805, merged by the maintainer on 2026-11-22 20:27 UTC after he ran the integration tests against a built xmcp. Proof: https://registry.npmjs.org/@xmcp-dev/x402/1.4.0 (the pull request: https://github.com/basementstudio/xmcp/pull/805)

```
curl -s https://registry.npmjs.org/@xmcp-dev/x402/-/x402-1.4.0.tgz | tar -xzOf - package/dist/verify.js | grep -c x402Version
```

Known open issue in this package, from our earlier claims-file change (#772): if a write to the claims file fails partway, the store refuses further claims until restart, and the server reports this only as a rejected payment, with no separate operator log line. It fails closed (no call is served unpaid), but it is not fixed yet.
