# 2026-10-11: an x402 directory now lists a way to take Nano beside USDC

Window: 2026-10-10 05:20 UTC to 2026-10-11 05:20 UTC. One item had an impact someone outside the project can check.

**gold-402, a public directory of x402 tools, now lists dual-rail.** dual-rail is a Python and Node acceptor. A
seller already paid in USDC over x402 can add a Nano (XNO) leg next to it. A 402 that names an XNO address and amount
is settled against a Nano node, and every other payment goes to the seller's existing facilitator as before. The
maintainer merged the entry on 2026-10-11 because "the README walks through settling an XNO 402 beside a USDC rail".
The entry is on the directory's SDK shelf and in its README.
