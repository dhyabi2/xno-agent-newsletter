# 2026-11-04: a .NET x402 client can now pay in Nano, and an open skills catalog can check a Nano payment

**[michielpost/x402-dotnet #24](https://github.com/michielpost/x402-dotnet/pull/24)** was merged on 2026-11-03 at 12:08 UTC (commit [`e1586ca`](https://github.com/michielpost/x402-dotnet/commit/e1586ca)). It adds `x402.Client.Nano` to this .NET x402 library: a `NanoWallet` that pays `exact` payment requirements on `nano:mainnet` in XNO, with the key kept in your own node or signer. An hour later the maintainer bumped the package to v0.0.2 ([`659d884`](https://github.com/michielpost/x402-dotnet/commit/659d884)). If you build agents in C#, a 402 priced in XNO can now be paid with the same client you already use for the EVM and Solana networks.

```
git clone -q --depth 3 https://github.com/michielpost/x402-dotnet && grep -n "x402.Client.Nano" x402-dotnet/README.md
```

What this does not show: the package was not on nuget.org when we checked (2026-11-04 05:27 UTC), so for now you build it from source. No payment through it has been traced yet.

**[sickn33/agentic-awesome-skills #2244](https://github.com/sickn33/agentic-awesome-skills/pull/2244)** was merged on 2026-11-03 at 20:26 UTC (commit [`556c50e`](https://github.com/sickn33/agentic-awesome-skills/commit/556c50e)). The catalog now carries `nano-settlement-verify`: a read-only check a seller runs before serving a paid call. It asks a public node whether a block hash paid this account exactly the quoted amount and whether the network confirmed it. No seed, no wallet. Until now the catalog had a skill for taking USDC on Base and none for checking a Nano settlement.

```
git clone -q --depth 1 https://github.com/sickn33/agentic-awesome-skills && head -12 agentic-awesome-skills/skills/nano-settlement-verify/SKILL.md
```
