# 2026-10-12: an x402 directory now lists a Nano settlement library for sellers

Window: 2026-10-11 05:20 UTC to 2026-10-12 05:20 UTC. One item had an impact someone outside the project can check.

**gold-402, a public directory of x402 tools, now lists nano-invoice.** nano-invoice is a Python library for the
settlement side of an x402 seller. A seller adds a `nano:mainnet` entry to its `accepts[]` next to the USDC entry it
already has; each invoice gets its own tagged amount, one Nano (XNO) block settles one invoice, and refunds go to the
sender the ledger names. The maintainer had invited the entry, and merged it on 2026-10-12 at 04:34 UTC with "Merging
as written." It is on the directory's SDK shelf and in its README.
