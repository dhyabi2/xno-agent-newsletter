# A public 402 directory now checks Nano payout accounts on chain

**ArcedeDev/open-402 #52, merged into main 2026-11-13 (b7f0097).** Open 402 Directory, an open registry of paid APIs that use HTTP 402 payment protocols, maintained outside this project, used to verify a listed API's payout address only against Base USDC transfers. It now also reads a declared `nano:mainnet` / XNO payout account on a Nano node: `account_info` for the confirmed height, then `account_history` for the account's confirmed receive blocks, through the same queue and the same address limit as Base. It reports activity only (how many confirmed receives, first and last time, last block hash) and claims nothing about a particular request being settled. A seller that lists a Nano account there can now show independently read activity beside the USDC sellers. We wrote the change; the project's maintainer merged it. Proof: https://github.com/ArcedeDev/open-402/pull/52

```
curl -sS https://raw.githubusercontent.com/ArcedeDev/open-402/b7f0097/scripts/watchers/nano-verifier.ts | grep -n account_history
```
