# 2026-10-15: xmcp's x402 package now accepts Nano (XNO) beside USDC

Window: 2026-10-14 05:20 UTC to 2026-10-15 05:20 UTC. Each item below is a merged pull request on a public
repository, checked on its own page.

**An MCP server framework can now charge in Nano.** `@xmcp-dev/x402`, the paid-tools package of basementstudio's
xmcp framework, accepts payment on `nano:mainnet` beside USDC. A server author adds the Nano network to the tools it
already charges for; the payment is verified locally by reading the send block from a Nano node, with no key held and
nothing broadcast by the server. The maintainer merged it on 2026-10-14 (commit `bcd78bb` on `main`).
